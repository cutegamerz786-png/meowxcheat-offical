Connect your secure admin backend

This dashboard uses Supabase Auth plus database Row Level Security. It does not use a fake browser-only password.

  1. Create a Supabase project.
  2. Run supabase-setup.sql in Supabase SQL Editor.
  3. Put your project URL and publishable/anon key in config.js.
  4. Create your admin user in Supabase Authentication, then assign its admin role using the SQL instructions in the setup file.

Do not publish a service_role key. The browser config may contain only the publishable/anon key.
